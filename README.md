# My Portfolio & Python Projects

Welcome to my repository! This contains my personal portfolio website and the Python projects I am building as I train to become a Full Stack Developer.

## 🚀 Projects Included

### 1. Infinite Calculator (`calculator.py`)
A robust command-line calculator that runs in a continuous loop. 
* **Features:** Supports addition, subtraction, multiplication, and division. Includes error handling, a "kill switch" to exit the program cleanly, and is wrapped in a reusable Python function.
* **How to run:** Open your terminal and run `python calculator.py`.

### 2. Secret Vault Game (`secret_vault.py`)
A text-based guessing game. 
* **Features:** Uses `for` loops and conditional logic. Locks the user out after 3 failed attempts.
* **How to run:** Open your terminal and run `python secret_vault.py`.

### 3. The ATM Simulator (`atm_simulator.py`)
A simulation of an ATM transaction loop.
* **Features:** Uses `while` loops to keep the session active and handles user choices until they decide to quit.
* **How to run:** Open your terminal and run `python atm_simulator.py`.
